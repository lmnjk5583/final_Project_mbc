## 05. 핵심 기능 상세

### 핵심 알고리즘: Grid Flow Map 학습 원리

**학습 단계 (learning_frames)**
- 정상 차량 이동벡터 → 15×15 셀에 EMA(α=0.1) 누적

**탐지 단계**
- 차량 방향 벡터 vs Flow Map → 이중 선형 보간 → cos θ 계산

**판정 단계**
- 투표(agree/disagree) + 히스테리시스 → 역주행 확정

```
cos θ = (ndx × flow_vx) + (ndy × flow_vy)
θ < -0.5  →  역방향 판정
```

### 신기능 개발 — 교통 정체 감지 엔진
#### traffic_analyzer.py 신규 모듈

```
🎥 CCTV 프레임 입력
        ↓
🔍 YOLO11n + ByteTrack
   active_ids, trajectories, bbox
        ↓
📊 traffic_analyzer.py 신규
   그리드 셀별 차량 밀도 계산 / 평균·중앙 속도 계산 / 시계열 버퍼 관리 최근 30초
        ↓
🧠 TrafficAnalyzer + CongestionPredictor 통합
   SMOOTH/SLOW/CONGESTED 분류 / 속도+밀도 기반 임계값 판단 / 히스테리시스 오탐 억제
        ↓
🚨 이상 징후 통합 판정 엔진
   INFO/CAUTION/WARNING/CRITICAL
        ↓
🖥️ visualizer.py + logger.py 확장
   정체 오버레이 + CSV 컬럼 추가
```

> *(우측 상단 참고: jam_score = 속도 50% + dwell 30% + 밀도 20%)*

**정체 레벨 다이어그램**

| 레벨 | 판정 기준 | 색상 |
|------|-----------|------|
| 🟢 SMOOTH (원활) | jam_score < 0.25 | 초록 |
| 🟡 SLOW (서행) | 0.25 ≤ jam_score < 0.55 | 노랑 |
| 🔴 CONGESTED (정체) | jam_score ≥ 0.55 | 빨강 |

> *Fundamental Diagram: 교통류 기본 다이어그램 — 속도와 밀도의 역관계 원리 적용*
