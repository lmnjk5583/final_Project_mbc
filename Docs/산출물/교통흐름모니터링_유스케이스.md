## 범 례

| 표기 | 의미 |
|---|---|
| ✅ Phase 1 완료 UC | Phase 1 개발이 완료된 유스케이스 |
| UC (역주행 / 공통) | 역주행 탐지 및 공통 유스케이스 |
| ──── 액터 연결 (association) | 액터와 유스케이스 간 연결 관계 |
| - - «include» (포함 관계) | 유스케이스가 다른 유스케이스를 반드시 포함 |
| - - «extend» (확장 관계) | 유스케이스가 다른 유스케이스를 조건부로 확장 |
| - - - - ACT-04 연결 (Phase 3) | Phase 3에서 연결 예정인 웹 클라이언트 관계 |
