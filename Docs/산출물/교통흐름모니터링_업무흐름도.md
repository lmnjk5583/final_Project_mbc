# 고속도로 이상징후 탐지 시스템 v2.0 | 업무흐름도

---

## 전체 흐름 개요

```
시작
 └→ 시스템 초기화 (Config / State / 모듈 생성)
      └→ [분기] flow_map.npy 존재? (is_learning = True)
           ├→ Yes → 학습 모드 설정
           └→ No  → 탐지 모드 준비 (flow_map 로드 완료)
```

---

## 상세 업무 흐름

### 1단계. 시스템 초기화

- Config / State / 모듈 생성

**분기 조건:** `flow_map.npy` 파일 존재 여부 확인

- **존재하지 않을 경우 (No):** 탐지 모드 준비 → flow_map 로드 완료
- **존재할 경우 (Yes):** 학습 모드 설정 (`is_learning = True`)

---

### 2단계. 영상 열기 & 그리드 초기화

- `VideoCapture` + `FlowMap.init_grid`

---

### 3단계. 프레임 루프

#### 3-1. 프레임 읽기 (`cap.read()`)

**분기 조건:** 프레임 있음 여부

- **프레임 없음 (No):** 영상 종료 → 루프 탈출
- **프레임 있음 (Yes):** 다음 단계 진행

---

### 4단계. 차량 감지 및 추적

- **YOLO11n** 차량 감지 + **ByteTrack** 추적
- **BBox EMA 안정화** (`BBoxStabilizer`)

---

### 5단계. 모드 분기

**현재 모드에 따라 LEARNING 분기 / DETECTING 분기로 구분**

---

## LEARNING 분기

### L-1. 이동 벡터 → FlowMap EMA 학습

- `flow_map.learn_step` 실행

### L-2. 학습 완료 여부 확인

**분기 조건:** N프레임 경과 여부

- **미완료 (No):** 프레임 루프 복귀
- **완료 (Yes):**
  - 공간 보정 (smoothing) + `flow_map.npy` 저장
  - DETECTING 모드로 전환

---

## DETECTING 분기

### D-1. 카메라 전환 감지

**분기 조건:** 카메라 전환 여부

- **전환됨 (Yes):**
  - Flow Map 초기화
  - RELEARNING 모드로 전환
  - `passage_tracker.reset()`
  - `congestion_judge.clear()`

- **전환 없음 (No):** 아래 단계 계속 진행

### D-2. ID 재매칭 시도

- `check_reappear` — **3중 게이트** 방식

### D-3. 궤적 업데이트

- `trajectories` 추가

### D-4. 속도 & 방향 계산

- `velocity_window` 기준으로 속도 및 방향 산출

### D-5. 역주행 탐지

- **FlowMap Cosine Similarity** 다중 포인트 투표

**분기 조건:** 역주행 확정 여부

- **확정 (Yes):**
  - W 라벨 부여 (W1 / W2)
  - 경고 박스 + 알림 표시

- **미확정 (No):** 다음 단계 진행

### D-6. 교통 통계 기록

- `passage_tracker.record_frame_stats()`

### D-7. 교통 흐름 분석

- `traffic_analyzer.update()`
  - `feature_extractor.compute()`
  - `congestion_judge.update()`

**분기 조건:** `jam_score ≥ threshold`

- **Yes (정체 판정):**
  - 정체 경보 표시 (레벨 배지·히트맵·지속시간)
- **No:** 다음 단계 진행
