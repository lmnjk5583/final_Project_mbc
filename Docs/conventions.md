## 산출물 파일 위치

산출물은 모두 `.md` 파일로 변환하여 `Docs/산출물/`에 관리.
직접 편집 가능 — 수정 후 `dev_guide.md`와 동기화 확인.

| 파일 | 경로 |
|------|------|
| 기획서 | `Docs/산출물/교통흐름모니터링_기획서.md` |
| 화면설계서 | `Docs/산출물/교통흐름모니터링_화면설계서.md` |
| 인터페이스명세서 | `Docs/산출물/교통흐름모니터링_인터페이스명세서.md` |
| 프로그램설계서 | `Docs/산출물/교통흐름모니터링_프로그램설계서.md` |

> N드라이브 `.docx`/`.xlsx` 원본은 보관용으로만 유지. 수정 작업은 위 .md 파일에서 진행.

## 산출물 충돌 보고 형식

산출물 `.md` 수정 시 내용 충돌을 보고할 때 아래 형식 사용:

```
**[충돌 N] 문서명 — 섹션명**

| 항목 | 현재 내용 | 올바른 내용 |
|------|-----------|-------------|
| ... | ... | ... |

→ 수정 위치: (문서 내 정확한 위치 — 섹션·표·행 지정)
```

## Git 커밋 메시지 형식

```
[담당자] 작업내용 요약
```

예시:
- `[대원] 정체탐지 threshold 로직 구현`
- `[수빈] 화면설계서 v1.1 jam_score 기준 반영`
- `[수빈] QA 체크리스트 업데이트`
